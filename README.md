# ESP32 I2C PROJECT

## Description
This project demonstrates UART (Inter Integrated Circuit) serial communication between an ESP32 and a PN532,EEPROMs.temperature, pressure, accelerometers.

The ESP32 firmware is developed using ESP-IDF.

The project covers basic I2C communication, including data transmission, data reception.

It serves as a practical introduction to embedded systems communication and provides a foundation for integrating microcontrollers with Linux-based systems in robotics and IoT applications.
